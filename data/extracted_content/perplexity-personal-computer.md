# Perplexity Personal Computer

Statut : contenu lu le 2026-05-06  
Source : https://www.blogdumoderateur.com/perplexity-personal-computer-agent-ia-controle-mac/

## Synthese

Perplexity Personal Computer est un agent IA pour Mac capable d'agir sur les fichiers locaux, les applications macOS, le web via Comet et des commandes vocales. L'article indique qu'il est reserve aux abonnes Max et optimise pour tourner en continu, notamment sur Mac mini.

Ce qui compte pour l'apprentissage : ce n'est pas seulement l'outil, c'est le pattern "ordinateur dedie a agents".

## Concepts a integrer

- agent local,
- acces fichiers et applications,
- sandbox,
- actions traceables et reversibles,
- controle humain,
- usage 24/7 pour routines.

## Action 30 minutes

Dessiner une architecture locale :

- dossiers autorises,
- comptes applicatifs,
- actions interdites,
- logs,
- kill switch,
- validation humaine.

## Mini-projet

Prototype local "agent admin" :

1. Dossier test avec fichiers factices.
2. L'agent propose un rangement.
3. Il renomme dans un dossier sandbox.
4. Il produit un log reversible.
