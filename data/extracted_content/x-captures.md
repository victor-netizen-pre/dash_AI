# Captures et textes X a recuperer

Statut : contenu non lu automatiquement.

## Pourquoi ce fichier existe

Les liens X/Twitter ne sont pas lisibles de maniere fiable depuis l'environnement actuel. Les objets des mails donnent une intention, mais pas le contenu exact.

Pour eviter de construire une synthese bidon, chaque post X doit etre enrichi par une des methodes suivantes :

- coller le texte du post,
- ajouter une capture,
- fournir un lien miroir fiable,
- ouvrir le post dans une session authentifiee et copier le contenu.

## Format attendu

```md
## URL

Texte du post :

Auteur :

Date :

Concepts :

Action 30 min :

Statut :
```
